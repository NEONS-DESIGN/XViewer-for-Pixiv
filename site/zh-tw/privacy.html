隱私政策

最後更新日期：2026年9月27日 / 制定日期：2026年9月17日

本擴充功能不會收集任何個人資訊。

除了您正在開啟的 pixiv 之外，不會將資料傳送到任何地方。 儲存的只有您選擇的設定項目，以及最後看到的 pixiv 顯示語言。以下為詳細說明。

1. 適用範圍

本政策適用於瀏覽器擴充功能「XViewer for Pixiv」（於 Chrome 線上應用程式商店、Edge 附加元件及 Firefox 附加元件 發布的版本。以下稱「本擴充功能」）以及本網站 （xviewer.neonsdesign.com）。

本擴充功能是為 pixiv（https://www.pixiv.net/）的用戶頁面加入專屬圖片檢視器的非官方工具。 並非由 pixiv Inc. 製作或發布，與該公司沒有任何關係。 關於 pixiv 本身如何處理個人資訊，請參閱 pixiv Inc. 的隱私政策。

2. 不收集的資訊

本擴充功能不會收集以下任何資訊。既不會取得，也不會儲存或傳送。

  • 個人識別資訊 — 姓名、地址、電子郵件地址、年齡、身分識別號碼等
  • 健康相關資訊
  • 財務狀況及付款相關資訊
  • 驗證相關資訊 — 密碼、認證資訊、安全提示問題、PIN 碼等
  • 個人通訊 — 電子郵件、訊息等
  • 位置資訊 — 地區、IP 位址、GPS 座標等
  • 網頁瀏覽紀錄 — 瀏覽過的頁面清單及其相關資料
  • 使用者活動 — 點擊、滑鼠位置、捲動、按鍵輸入的紀錄等
  • 網站內容 — 圖片、文字、音訊、影片等的儲存或向外傳送

本擴充功能為了在檢視器中顯示 pixiv 的圖片、作品說明及評論而載入這些內容， 但這些內容只會為了繪製畫面而在瀏覽器的記憶體中處理。 既不會被儲存，也不會傳送到包括作者在內的第三方可以取得的地方。

您在對話框中撰寫的評論與回覆也是如此。 按下發送按鈕時，只會直接交給 pixiv 本身的 API，本擴充功能既不會儲存， 也不會傳送給包括作者在內的第三方。發表的評論的公開範圍及處理方式， 與從 pixiv 本身的評論欄發表時完全相同。

3. 儲存的資訊

本擴充功能儲存的資訊有 2 種。一種是在彈出視窗中選擇的設定， 另一種是最後看到的 pixiv 顯示語言。兩者的儲存位置不同，詳情如下。

設定儲存在瀏覽器的設定同步空間（chrome.storage.sync）， 位於您的瀏覽器中；若您啟用了瀏覽器同步，也會位於該瀏覽器的帳戶中 （Chrome 為 Google 帳戶、Edge 為 Microsoft 帳戶、Firefox 為 Mozilla 帳戶）。 包括作者在內的第三方都無法讀取。

儲存的設定為以下 11 項。每一項都是布林值，或是既定選項中的其中 1 個。

  • 是否使用檢視器
  • 圖片解析度
  • 預先載入的張數
  • 是否顯示側邊欄
  • 側邊欄的捲動方式
  • 是否點擊背景關閉
  • 是否點擊以原尺寸顯示
  • 網格中 Tab 移動的處理方式
  • 是否隱藏精選欄
  • 無限捲動的行為
  • 設定畫面的配色

瀏覽過的作品 ID、用戶 ID、瀏覽紀錄，以及按讚或收藏的紀錄，一概不會儲存。

設定畫面（彈出視窗）並非 pixiv 的頁面，因此無法自行判斷顯示語言。 所以，會將在 pixiv 頁面上執行的腳本所看到的顯示語言儲存在 chrome.storage.local 中， 再由設定畫面讀取。儲存的值只有 ja 或 en 這類的 1 個語言代碼， 不包含任何可識別個人的資訊。此空間只存在於裝置中，不在瀏覽器的同步範圍內。

刪除已儲存的資訊

按下設定畫面中的「重設設定」，已儲存的值就會恢復為預設值。 從瀏覽器移除本擴充功能後，儲存空間也會一併刪除。

4. 通訊對象

本擴充功能沒有伺服器。完全不會與作者管理的伺服器通訊。 只會與您已經開啟的 pixiv，以及其用於提供圖片的伺服器通訊。

  • https://www.pixiv.net/ — 取得作品資訊、評論及作者資訊。傳送按讚、收藏、追蹤、發表評論與回覆，以及刪除自己的評論的請求（皆僅在您按下按鈕時）
  • https://i.pximg.net/ — 載入作品圖片及動圖的資料
  • https://s.pximg.net/ — 載入評論中貼圖與表情符號的圖片

這些都是以一般瀏覽器瀏覽 pixiv 時也會發生的通訊。 完全沒有加入任何流量分析、廣告或當機回報之類的功能。

5. 要求的權限及其理由

本擴充功能要求的權限只有以下 2 項。不會要求存取其他網站的權限。

storage

用於儲存前述的設定，以及最後看到的 pixiv 顯示語言。設定是在工具列的彈出視窗中變更， 並由在 pixiv 頁面上執行的腳本讀取，因此需要一個能在兩者之間共用值的方法。 顯示語言則相反，由在 pixiv 頁面上執行的腳本寫入，再由彈出視窗讀取。

https://www.pixiv.net/*

這是為了顯示檢視器，而在 pixiv 的頁面上執行腳本的權限。 用於變更頁面的顯示、以您的登入狀態呼叫 pixiv 本身的 API， 以及偵測頁面的切換。僅限於這 1 個網站， 不會要求其他網站或以所有網站為對象的權限。

6. Cookie 與認證資訊的處理

本擴充功能不會讀取您的 Cookie。 呼叫 pixiv 的 API 時，瀏覽器會和一般瀏覽頁面時一樣附上登入狀態。 本擴充功能不會處理登入資訊本身。

按讚、收藏、追蹤、發表評論與回覆，以及刪除自己的評論， 只會在您按下對話框中的按鈕時執行。不會自動傳送。 另外，依照 pixiv 的規格，讚無法取消。評論刪除後也無法復原，因此會經過兩段式確認。

7. 提供給第三方

由於沒有收集任何資訊，因此也沒有可以提供給第三方的資訊。 本擴充功能不會販售、轉讓或分享使用者的資料。 此外，不會將資料用於與單一用途（為 pixiv 的用戶頁面加入圖片檢視器）無關的目的， 也不會用於信用評估或貸款的目的。

8. 關於本網站

本網站是在 GitHub Pages（GitHub, Inc.）上公開的靜態頁面。 完全沒有使用流量分析、廣告、外部字型或外部腳本。 本網站也不會設定 Cookie。

不過，主機服務商 GitHub, Inc. 可能會因提供服務而記錄存取紀錄 （IP 位址等）。這並非由作者管理。 詳情請參閱 GitHub 公司的隱私權聲明。

另外，本網站刊登的靜態螢幕截圖，是為了說明運作方式而使用的示範用假資料， 並非真實的作品資訊或評論。

另一方面，說明無限捲動的影片，是實際瀏覽 pixiv 公開帳號的螢幕錄影。 畫面中顯示的作品資訊與計數均未經過加工。

9. 關於兒童的使用

本擴充功能不會向任何使用者收集個人資訊。無論年齡為何，這一點都不會改變。 另外，有年齡限制的作品，其顯示依照 pixiv 端的設定。 本擴充功能不會規避年齡限制。

10. 本政策的變更

變更本政策時，會更新此頁面，並修改開頭的最後更新日期。 進行重大變更時，也會在擴充功能的更新資訊中通知。

11. 聯絡方式

關於本政策及本擴充功能的詢問、錯誤回報、問題及需求，請透過以下方式聯絡。

  • 聯絡表單（錯誤回報、問題、需求）：開啟 Google 表單。表單是英文的，但用中文填寫也沒有問題
  • GitHub 的 Issues：給開發者的管道（需要 GitHub 帳號）

透過聯絡表單收到的資訊

聯絡表單使用的是 Google 表單。收到的只有您填寫的以下 3 個項目。

  • 詢問類型（必填）— 問題 / 錯誤回報 / 功能需求其中之一
  • 詢問內容（必填）
  • 電子郵件地址（選填）— 僅在希望收到回覆時填寫

此表單不會要求登入 Google 帳戶，也不會自動記錄已登入帳戶的電子郵件地址。 若未填寫電子郵件地址，作者就沒有任何方法與您聯絡。

收到的內容，只會用於回覆，以及修正本擴充功能的錯誤與改善功能。 不會提供給作者以外的第三方。

填答內容會儲存在 Google 的服務上。開啟或送出表單時，Google 端如何處理資訊， 依照 Google 的隱私權政策。 寫在 GitHub Issues 中的內容，會刊登在任何人都能閱讀的公開場所。請勿寫入個人資訊。
