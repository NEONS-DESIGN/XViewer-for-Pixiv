支援 Chrome / Brave / Edge / Firefox

像瀏覽 X 一樣，瀏覽 pixiv。

在用戶頁面點擊作品後，不必跳轉頁面，就會直接在原處開啟對話框。 從切換多張圖片、播放動圖、閱讀作品說明與評論，到按讚、收藏、追蹤及發表評論， 全都能在對話框中完成。 關閉後，就會回到原本的網格與原本的捲動位置。

不離開列表，前往下一個作品

每次開啟作品，頁面就會切換；每次返回，又找不到原本的捲動位置。這個擴充功能就是為了免去這樣的來回而生。

以對話框開啟

接收網格中的點擊，不跳轉頁面直接顯示。網址會替換為作品頁面的網址，因此也能重新整理或分享。

切換多張圖片

用左右鍵或畫面兩端的箭頭翻頁。開啟設定後，點擊畫面左右邊緣也能翻頁。會預先載入前後的圖片，切換時不必等待。

從作品到作品

用上下鍵移到網格中的上一個或下一個作品。開啟設定後，點擊畫面上下邊緣也能切換。到達盡頭時，會自動載入下一頁的作品。在插畫與漫畫分頁中，只會瀏覽該類型的作品。

播放動圖

解壓縮 zip 並組合影格，直接在原處播放。也支援暫停。

原尺寸顯示

點擊圖片後，會以原尺寸填滿整個畫面開啟。開啟時也能直接翻頁，可以一邊確認細節一邊往下看。

閱讀、撰寫評論

以圖片顯示貼圖與表情符號，也支援展開回覆與載入更多評論。發表評論、回覆及刪除自己的評論，都能在對話框開啟的狀態下進行。

按讚與收藏

包括追蹤，以及分享到 X / Facebook / Pawoo / 複製連結，都能在對話框中操作。按住 Shift 收藏即為不公開。自己的作品不會顯示這些按鈕。

深色與淺色

檢視器的配色會跟隨 pixiv 本身的設定，不必重複設定。設定畫面的配色可從右上角的圖示切換。

作品說明和評論，都在圖片旁邊

側邊欄會列出作品說明、標籤、投稿時間、讚數、收藏數、瀏覽量，以及作者的頭像與追蹤按鈕。 評論中的貼圖與表情符號會直接以圖片繪製，回覆也能在原處展開。

  • 可選擇整個側邊欄一起捲動，或只捲動評論
  • 即使載入失敗，也能從「重試」繼續讀取
  • 在其他分頁按過的讚不會重複計算
  • 也可以隱藏側邊欄，只看圖片

回覆也不必關閉，直接進行

評論與回覆可以在對話框開啟的狀態下發表。輸入欄會隨著輸入的行數延伸， 表情符號與貼圖可從面板中選擇。Ctrl + Enter 發送，Enter 為換行。

  • 自己的評論在經過兩段式確認後即可刪除
  • 有尚未發送的內容時，按 Esc 不會關閉對話框
  • 發表的評論與在 pixiv 本身撰寫的評論視為相同

讓列表不再中斷

可將插畫與漫畫列表的分頁改為往下持續載入的形式。 網址中的頁碼會跟隨畫面上顯示的頁面，因此重新整理後也能回到差不多的位置。

  • 可從「捲到底部時載入」/「隨時預先載入下一頁」中選擇
  • 可隱藏個人資料的精選欄，讓作品列表立刻映入眼簾

細緻地設定擴充功能

從工具列的圖示開啟。分為檢視器、圖片、用戶頁面、操作 4 個類別，從顯示方式到操作習慣，都能依自己的喜好調整。

  • 可依網路環境或喜好，選擇圖片解析度與預先載入的張數
  • 連側邊欄的顯示方式、捲動方式，以及點擊背景是否關閉、點擊畫面邊緣是否翻頁都能變更
  • 關閉檢視器本身，就會恢復為 pixiv 的標準行為

設定可以做到的事

全部都能從工具列的彈出視窗變更。設定會儲存在瀏覽器的同步儲存空間中，不會傳送到外部。

類別 項目 預設 效果

按鍵操作

←→在同一作品中翻頁（原尺寸顯示中也相同）
↑↓移到上一個或下一個作品
CtrlEnter發送評論（Mac 為 Cmd）
Esc從最上層的項目依序關閉
Tab在對話框內移動焦點

Esc 會依表情符號面板、原尺寸顯示與分享選單、對話框的順序關閉。有尚未發送的評論時，不會關閉對話框。
撰寫評論時，Enter 為換行，← → ↑ ↓ 會用來移動游標（不會切換作品）。

運作環境

可在支援 Manifest V3 的 Chromium 系瀏覽器與 Firefox 上運作。

支援的瀏覽器

Chrome、Brave、Edge 等 Chromium 系瀏覽器。需要 Chrome 120 以上。Edge 也可以從 Edge 附加元件安裝。Firefox（Firefox 140 以上的桌面版）可以從 Firefox 附加元件 安裝。不支援 Safari。

適用頁面

https://www.pixiv.net/ 的用戶頁面。在其他網站上不會運作。

授權

原始碼公開於 GitHub。免責聲明與隨附的第三方素材的標示，位於設定畫面的「授權」分頁。

支援語言

擴充功能的顯示語言會配合 pixiv 的顯示語言切換。此表列出的是 pixiv 可選擇的 7 種顯示語言。當 pixiv 以「視需求而定」的語言顯示時，擴充功能會以英文顯示。

錯誤回報與需求

錯誤回報、問題及功能需求，請透過聯絡表單寄送。表單是英文的，但用中文填寫也沒有問題。有使用 GitHub 的話，也可以透過 Issues 回報。

資料不會離開 pixiv

本擴充功能沒有作者的伺服器。只會與您正在開啟的 pixiv 及其圖片 CDN 通訊。

不收集的資料

瀏覽紀錄、作品 ID、用戶 ID、Cookie、認證資訊、個人資訊。這些都不會取得、儲存或傳送。您撰寫的評論也只會當場交給 pixiv，不會留在擴充功能中。

儲存的資料

您選擇的 13 項設定，以及最後看到的 pixiv 顯示語言。兩者都只保留在瀏覽器中，不會傳到外部伺服器。

要求的權限

只有 storage 與 https://www.pixiv.net/* 這 2 項。不會要求存取其他網站的權限。
