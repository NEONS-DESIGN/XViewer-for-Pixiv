개인정보보호방침

최종 수정일: 2026년 9월 27일 / 제정일: 2026년 9월 17일

이 확장 프로그램은 어떠한 개인정보도 수집하지 않습니다.

사용자가 열어 둔 pixiv 이외의 곳으로 데이터를 보내지 않습니다. 저장하는 것은 사용자가 고른 설정 항목과 마지막으로 본 pixiv의 표시 언어뿐입니다. 아래는 그 자세한 내용입니다.

1. 적용 범위

본 방침은 브라우저 확장 프로그램 ‘XViewer for Pixiv’ (Chrome 웹 스토어·Edge 추가 기능·Firefox Add-ons에서 배포하는 것. 이하 ‘본 확장 프로그램’) 및 본 사이트 (xviewer.neonsdesign.com)에 적용됩니다.

본 확장 프로그램은 pixiv (https://www.pixiv.net/)의 유저 페이지에 독자적인 이미지 뷰어를 추가하는 비공식 도구입니다. pixiv Inc.에서 제작·배포하는 것이 아니며, 이 회사와는 아무런 관계가 없습니다. pixiv 자체의 개인정보 취급에 대해서는 pixiv Inc.의 개인정보보호방침을 확인해 주세요.

2. 수집하지 않는 정보

본 확장 프로그램은 다음 중 어떠한 정보도 수집하지 않습니다. 가져오지도, 저장하지도, 전송하지도 않습니다.

  • 개인 식별 정보 — 이름, 주소, 이메일 주소, 나이, 개인 식별 번호 등
  • 건강 정보
  • 재무 상황 및 결제 정보
  • 인증 정보 — 비밀번호, 자격 증명, 보안 질문, PIN 등
  • 개인 커뮤니케이션 — 이메일, 메시지 등
  • 위치 정보 — 지역, IP 주소, GPS 좌표 등
  • 웹 기록 — 방문한 페이지 목록과 그 관련 데이터
  • 사용자 활동 — 클릭, 마우스 위치, 스크롤, 키 입력 기록 등
  • 웹사이트 콘텐츠 — 이미지, 텍스트, 음성, 동영상 등의 저장이나 외부 전송

본 확장 프로그램은 pixiv의 이미지와 작품 설명, 댓글을 뷰어에 표시하기 위해 불러오지만, 이는 화면에 그리기 위해 브라우저의 메모리에서 다뤄질 뿐입니다. 저장되지도 않고, 제작자를 포함한 제3자가 가져갈 수 있는 곳으로 보내지지도 않습니다.

사용자가 모달 안에서 쓴 댓글이나 답변도 마찬가지입니다. 전송 버튼을 눌렀을 때 pixiv 자체의 API로 그대로 전달할 뿐이며, 본 확장 프로그램이 저장하거나 제작자를 포함한 제3자에게 보내는 일은 없습니다. 작성한 댓글의 공개 범위와 취급은 pixiv 본체의 댓글란에서 작성한 경우와 완전히 같습니다.

3. 저장하는 정보

본 확장 프로그램이 저장하는 정보는 두 가지입니다. 하나는 팝업 화면에서 고른 설정, 다른 하나는 마지막으로 본 pixiv의 표시 언어입니다. 저장 위치는 각각 다르며, 자세한 내용은 다음과 같습니다.

설정은 브라우저의 설정 동기화 영역 (chrome.storage.sync)에 저장되며, 사용자의 브라우저와, 사용자가 브라우저 동기화를 켜 둔 경우에는 해당 브라우저의 계정 (Chrome이라면 Google 계정, Edge라면 Microsoft 계정, Firefox라면 Mozilla 계정) 안에 놓입니다. 제작자를 포함한 제3자는 이를 읽을 수 없습니다.

저장되는 설정은 다음 11개입니다. 모두 참/거짓 값이거나 정해진 선택지 중 하나입니다.

  • 뷰어를 사용할지 여부
  • 이미지 해상도
  • 미리 불러올 장수
  • 사이드바를 표시할지 여부
  • 사이드바 스크롤 방식
  • 배경 클릭으로 닫을지 여부
  • 클릭하여 원본 크기로 볼지 여부
  • 그리드의 Tab 이동 처리
  • 픽업 영역을 숨길지 여부
  • 무한 스크롤 동작
  • 설정 화면의 색상 구성

열람한 작품의 ID, 유저 ID, 열람 기록, 좋아요나 북마크 기록은 일절 저장하지 않습니다.

설정 화면 (팝업)은 pixiv 페이지를 가지고 있지 않으므로 표시 언어를 스스로 판단할 수 없습니다. 그래서 pixiv 페이지에서 작동하는 스크립트가 확인한 표시 언어를 chrome.storage.local에 저장하고, 설정 화면이 이를 읽습니다. 저장하는 값은 ja나 en 같은 언어 코드 하나뿐이며, 개인을 식별하는 정보는 포함되지 않습니다. 이 영역은 기기 안에만 놓이며, 브라우저의 동기화 대상이 되지 않습니다.

저장한 정보 삭제

설정 화면의 ‘설정 초기화’를 누르면 저장한 값이 기본값으로 돌아갑니다. 브라우저에서 본 확장 프로그램을 삭제하면 저장 영역째 삭제됩니다.

4. 통신 대상

본 확장 프로그램은 서버를 가지고 있지 않습니다. 제작자가 관리하는 서버와의 통신은 일절 발생하지 않습니다. 통신하는 곳은 사용자가 이미 열어 둔 pixiv와 그 이미지 전송용 서버뿐입니다.

  • https://www.pixiv.net/ — 작품 정보, 댓글, 작가 정보 가져오기. 좋아요, 북마크, 팔로우, 댓글과 답변 작성, 내 댓글 삭제의 전송 (모두 사용자가 버튼을 눌렀을 때만)
  • https://i.pximg.net/ — 작품 이미지와 움짤(우고이라) 데이터 불러오기
  • https://s.pximg.net/ — 댓글의 스탬프와 이모지 이미지 불러오기

이들은 모두 브라우저에서 pixiv를 평소처럼 열람할 때에도 발생하는 통신입니다. 접속 분석, 광고, 크래시 리포트와 같은 것은 일절 포함하지 않았습니다.

5. 요구하는 권한과 그 이유

본 확장 프로그램이 요구하는 권한은 다음 두 가지뿐입니다. 다른 사이트에 대한 접근 권한은 요구하지 않습니다.

storage

앞서 설명한 설정과 마지막으로 본 pixiv의 표시 언어를 저장하는 데 사용합니다. 설정은 툴바의 팝업에서 변경하고 pixiv 페이지에서 작동하는 스크립트가 읽으므로, 이 둘 사이에서 값을 공유할 수단이 필요합니다. 표시 언어는 그 반대로, pixiv 페이지에서 작동하는 스크립트가 쓰고 팝업이 읽습니다.

https://www.pixiv.net/*

뷰어를 표시하기 위해 pixiv 페이지에서 스크립트를 실행하는 권한입니다. 페이지 표시를 변경하는 것, pixiv 자체의 API를 사용자의 로그인 상태로 호출하는 것, 페이지 이동을 감지하는 것에 사용합니다. 이 한 사이트로 한정되어 있으며, 다른 사이트나 모든 사이트를 대상으로 하는 권한은 요구하지 않습니다.

6. 쿠키와 인증 정보의 취급

본 확장 프로그램은 사용자의 쿠키를 읽지 않습니다. pixiv의 API를 호출할 때는 브라우저가 일반 페이지 열람과 똑같이 로그인 상태를 붙입니다. 본 확장 프로그램이 로그인 정보 자체를 다루는 일은 없습니다.

좋아요, 북마크, 팔로우, 댓글과 답변 작성, 내 댓글 삭제는 사용자가 모달 안의 버튼을 눌렀을 때만 실행됩니다. 자동으로 전송되는 일은 없습니다. 또한 좋아요는 pixiv의 사양상 취소할 수 없습니다. 댓글 삭제도 되돌릴 수 없으므로 2단계 확인을 거칩니다.

7. 제3자 제공

수집하는 정보가 없으므로 제3자에게 제공하는 정보도 없습니다. 본 확장 프로그램은 이용자의 데이터를 판매, 양도, 공유하지 않습니다. 또한 단일 용도 (pixiv 유저 페이지에 이미지 뷰어를 추가하는 것)와 무관한 목적으로 데이터를 사용하지 않습니다. 신용도 판단이나 대출 목적으로 사용하지도 않습니다.

8. 본 사이트에 대하여

본 사이트는 GitHub Pages (GitHub, Inc.)에서 공개하는 정적 페이지입니다. 접속 분석, 광고, 외부 글꼴, 외부 스크립트는 일절 사용하지 않습니다. 본 사이트가 쿠키를 설정하는 일도 없습니다.

다만 호스팅 사업자인 GitHub, Inc.가 서비스 제공에 따라 접속 로그 (IP 주소 등)를 기록할 수 있습니다. 이는 제작자가 관리하는 것이 아닙니다. 자세한 내용은 GitHub의 개인정보 보호 선언 (Privacy Statement)을 확인해 주세요.

또한 본 사이트에 게재한 정지 화면 스크린숏은 동작을 설명하기 위한 데모용 더미 데이터이며, 실제 작품 정보나 댓글이 아닙니다.

한편, 무한 스크롤을 설명하는 동영상은 pixiv의 공개 계정을 실제로 열람한 화면 녹화입니다. 표시된 작품 정보나 카운터에는 손대지 않았습니다.

9. 어린이의 이용에 대하여

본 확장 프로그램은 어떠한 이용자로부터도 개인정보를 수집하지 않습니다. 나이와 관계없이 이는 변하지 않습니다. 또한 연령 제한이 있는 작품의 표시는 pixiv 측의 설정을 따릅니다. 본 확장 프로그램이 연령 제한을 우회하는 일은 없습니다.

10. 본 방침의 변경

본 방침을 변경하는 경우에는 이 페이지를 갱신하고 첫머리의 최종 수정일을 고칩니다. 중요한 변경을 하는 경우에는 확장 프로그램의 업데이트 정보로도 알립니다.

11. 문의

본 방침 및 본 확장 프로그램에 관한 문의, 버그 신고, 질문, 요청은 아래로 보내 주세요.

  • 문의 양식 (버그 신고·질문·요청): Google 양식 열기 (양식은 영어로 되어 있지만, 한국어로 작성하셔도 괜찮습니다)
  • GitHub Issues: 개발자용 창구 (GitHub 계정이 필요합니다)

문의 양식으로 받는 정보

문의 양식은 Google 양식을 사용합니다. 받는 것은 사용자가 입력한 다음 3개 항목뿐입니다.

  • 문의 유형 (필수) — 질문 / 버그 신고 / 기능 요청 중 하나
  • 문의 내용 (필수)
  • 이메일 주소 (선택) — 답변을 원하는 경우에만 입력해 주세요

양식은 Google 계정 로그인을 요구하지 않으며, 로그인 중인 계정의 이메일 주소를 자동으로 기록하지도 않습니다. 이메일 주소를 입력하지 않으면 제작자가 사용자에게 연락할 수단은 남지 않습니다.

받은 내용은 답변과 본 확장 프로그램의 버그 수정 및 개선을 위해서만 사용합니다. 제작자 이외의 제3자에게 제공하지 않습니다.

응답은 Google 서비스에 저장됩니다. 양식을 열거나 전송할 때 Google 측의 정보 취급은 Google의 개인정보처리방침을 따릅니다. GitHub Issues에 쓴 내용은 누구나 읽을 수 있는 공개된 곳에 올라갑니다. 개인정보는 적지 마세요.
