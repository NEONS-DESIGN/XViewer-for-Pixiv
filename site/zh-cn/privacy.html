隐私政策

最后更新日期：2026年10月1日 / 制定日期：2026年9月17日

本扩展程序不会收集任何个人信息。

除了你正在浏览的 pixiv 之外，不会向任何地方发送数据。 保存的只有你选择的设置项，以及最后看到的 pixiv 显示语言。详情如下。

1. 适用范围

本政策适用于浏览器扩展程序“XViewer for Pixiv”（在 Chrome 应用商店、Edge 加载项和 Firefox 附加组件上发布的版本，以下简称“本扩展程序”）以及本网站 （xviewer.neonsdesign.com）。

本扩展程序是一款为 pixiv（https://www.pixiv.net/）的用户页面添加独立图片查看器的非官方工具。 它并非由 pixiv Inc. 制作或发布，与该公司没有任何关系。 关于 pixiv 本身对个人信息的处理，请参阅 pixiv Inc. 的隐私政策。

2. 不收集的信息

本扩展程序不收集以下任何信息，既不获取，也不保存，更不发送。

  • 可识别个人身份的信息 — 姓名、地址、电子邮件地址、年龄、个人识别号码等
  • 健康信息
  • 财务状况和支付信息
  • 身份验证信息 — 密码、凭据、安全问题、PIN 码等
  • 个人通信 — 电子邮件、消息等
  • 位置信息 — 地区、IP 地址、GPS 坐标等
  • 网络浏览记录 — 浏览过的页面列表及其相关数据
  • 用户活动 — 点击、鼠标位置、滚动、按键输入的记录等
  • 网站内容 — 保存图片、文字、音频、视频等，或将其发送到外部

本扩展程序会为了在查看器中显示而加载 pixiv 的图片、作品说明和评论， 但这些内容只会为了在屏幕上显示而在浏览器的内存中处理。 既不会被保存，也不会被发送到包括作者在内的第三方能够获取的地方。

你在弹窗中写的评论和回复也是一样。 点击发送按钮时，内容只会原样提交给 pixiv 自身的 API，本扩展程序不会保存， 也不会发送给包括作者在内的第三方。所发表评论的公开范围和处理方式， 与在 pixiv 网站的评论栏中发表时完全相同。

3. 保存的信息

本扩展程序保存的信息有 2 种。一种是在弹出页面中选择的设置， 另一种是最后看到的 pixiv 显示语言。两者的保存位置不同，详情如下。

设置保存在浏览器的设置同步存储（chrome.storage.sync）中， 位于你的浏览器内；如果你启用了浏览器同步，还会保存在该浏览器的账户中 （Chrome 为 Google 账户，Edge 为 Microsoft 账户，Firefox 为 Mozilla 账户）。 包括作者在内的第三方都无法读取这些内容。

保存的设置为以下 20 项。每一项都是布尔值，或者是固定选项中的一个。（预加载的自定义张数为 1～10 的整数）

  • 是否使用查看器
  • 图片分辨率
  • 预加载的张数
  • 预加载的自定义张数
  • 是否预加载前后作品
  • 是否显示侧边栏
  • 侧边栏的滚动方式
  • 侧边栏宽度
  • 拉出的侧边栏宽度
  • 背景浓度
  • 一次读取的评论数
  • 点击背景时是否关闭
  • 点击画面边缘翻页的方式
  • 屏幕边缘点击区域大小
  • 点击时是否查看原图
  • 原图显示的点击区域宽度
  • 网格中 Tab 键导航的方式
  • 是否隐藏精选栏
  • 无限滚动的行为
  • 设置页面的配色

浏览过的作品 ID、用户 ID、浏览记录，以及点赞和收藏的记录，一概不会保存。

设置页面（弹出页面）不属于 pixiv 的页面，因此无法自行判断显示语言。 为此，在 pixiv 页面上运行的脚本会将其看到的显示语言保存到 chrome.storage.local 中， 再由设置页面读取。保存的值只有 ja 或 en 这样的 1 个语言代码， 不包含任何可识别个人身份的信息。该存储区域只存在于设备本地，也不会参与浏览器同步。

删除已保存的信息

点击设置页面中的“重置设置”，已保存的值将恢复为默认值。 从浏览器中移除本扩展程序后，存储区域也会一并删除。

4. 通信对象

本扩展程序没有服务器，完全不会与作者管理的服务器通信。 只与你已经打开的 pixiv 及其图片分发服务器通信。

  • https://www.pixiv.net/ — 获取作品信息、评论和作者信息。发送点赞、收藏、关注、发表评论和回复、删除自己的评论（均仅在你点击按钮时）
  • https://i.pximg.net/ — 加载作品图片和动图数据
  • https://s.pximg.net/ — 加载评论中贴图和表情的图片

以上通信在使用普通浏览器浏览 pixiv 时同样会发生。 本扩展程序没有加入任何访问统计、广告或崩溃报告之类的功能。

5. 请求的权限及其理由

本扩展程序请求的权限只有以下 2 项。不请求访问其他网站的权限。

storage

用于保存上述设置以及最后看到的 pixiv 显示语言。设置在工具栏的弹出页面中更改， 由在 pixiv 页面上运行的脚本读取，因此需要一种在两者之间共享数值的方式。 显示语言则正好相反，由在 pixiv 页面上运行的脚本写入，再由弹出页面读取。

https://www.pixiv.net/*

这是为了显示查看器而在 pixiv 页面上运行脚本的权限。 用于更改页面的显示、以你的登录状态调用 pixiv 自身的 API， 以及检测页面跳转。该权限仅限于这 1 个网站， 不请求针对其他网站或所有网站的权限。

6. Cookie 和身份验证信息的处理

本扩展程序不会读取你的 Cookie。 调用 pixiv 的 API 时，浏览器会像普通浏览页面时一样附带登录状态。 本扩展程序不会处理登录信息本身。

点赞、收藏、关注、发表评论和回复、删除自己的评论， 只会在你点击弹窗中的按钮时执行，不会自动发送。 另外，由于 pixiv 的机制，赞无法取消。删除评论后也无法恢复，因此设有两步确认。

7. 向第三方提供

由于没有收集任何信息，因此也没有向第三方提供的信息。 本扩展程序不会出售、转让或共享用户的数据。 此外，不会将数据用于与单一用途（为 pixiv 的用户页面添加图片查看器）无关的目的， 也不会用于信用评估或贷款目的。

8. 关于本网站

本网站是发布在 GitHub Pages（GitHub, Inc.）上的静态页面。 完全不使用访问统计、广告、外部字体和外部脚本。 本网站也不会设置 Cookie。

不过，托管服务商 GitHub, Inc. 可能会在提供服务的过程中记录访问日志 （IP 地址等）。这些日志不由作者管理。 详情请参阅 GitHub 的隐私声明。

另外，本网站刊登的静态截图是为了说明功能而使用的演示用虚拟数据， 并非真实的作品信息或评论。

而说明无限滚动的视频，则是实际浏览 pixiv 公开账户时的屏幕录像。 其中显示的作品信息和计数均未经加工。

9. 关于儿童的使用

本扩展程序不会从任何用户处收集个人信息。无论年龄大小，这一点都不会改变。 另外，有年龄限制的作品的显示遵循 pixiv 的设置。 本扩展程序不会绕过年龄限制。

10. 本政策的变更

变更本政策时，将更新此页面，并修改开头的最后更新日期。 进行重要变更时，也会在扩展程序的更新说明中告知。

11. 联系方式

关于本政策及本扩展程序的咨询、问题反馈、疑问和需求，请通过以下方式联系。

  • 联系表单（问题反馈、咨询、需求）：打开 Google 表单。表单为英文，但可以直接用中文填写。
  • GitHub 的 Issues：面向开发者的渠道（需要 GitHub 账户）

联系表单接收的信息

联系表单使用的是 Google 表单。接收的只有你填写的以下 3 项内容。

  • 咨询类型（必填）— 提问 / 问题反馈 / 功能需求之一
  • 咨询内容（必填）
  • 电子邮件地址（选填）— 仅在希望收到回复时填写

该表单不要求登录 Google 账户，也不会自动记录已登录账户的电子邮件地址。 如果不填写电子邮件地址，作者将无法与你取得联系。

收到的内容仅用于回复你，以及修复本扩展程序的问题和改进功能。 不会提供给作者以外的任何第三方。

表单的提交内容保存在 Google 的服务中。打开或提交表单时 Google 对信息的处理， 遵循 Google 的隐私政策。 写在 GitHub Issues 中的内容会发布在任何人都能阅读的公开场所，请不要写入个人信息。
